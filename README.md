# NumeraLab

نسخهٔ جاری نامرالب، سرویس محاسبات عددی IEAUM روی numeralab.ieaum.ir.

npm ci
npm run lint
npm test
npm run build

پوشهٔ src شامل حل‌گر، مراحل حل و رابط پنل است. کد حساب‌ها، ربات و منطق آزمون از بستهٔ نسخه‌بندی‌شدهٔ @ieaum/platform در مخزن Salolita/ieaum دریافت می‌شود. api/portal.ts و src/register.tsx فقط اتصال به آن بسته‌اند.

برای انتشار نسخهٔ جدید ربات، ابتدا کد و portal/dist را در مخزن ieaum ثبت و سپس وابستگی این پروژه را به همان شناسهٔ ثابت ارتقا دهید. تغییر ieaum به‌تنهایی ربات فعال را تغییر نمی‌دهد.

ریشهٔ پروژهٔ Vercel همین پوشه و خروجی ساخت dist است. نام فعلی پروژهٔ ورسل می‌تواند numera-lab-v1 بماند. مخزن متصل باید Salolita/NumeraLab باشد. دامنه، تنظیمات محرمانه و پایگاه دادهٔ موجود حفظ می‌شوند.

فایل‌های presentation و API آن موقتاً برای حفظ ارائهٔ فعال باقی مانده‌اند تا مخزن مستقل ارائه‌طوری آماده شود.
